## About

I'm a frontend developer based in Lagos, Nigeria, currently in my final year of Software Engineering at Babcock University. I specialise in building clean, component-driven UIs with React and Next.js — the kind that don't need an explanation to navigate.

I care about the details: good component architecture, readable code, and interfaces that don't look like they were assembled from a UI kit someone found on Google.

Currently working on **Scope** — a job intelligence dashboard powered by the JSearch API.
